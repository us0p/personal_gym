# Personal GYM
A Client-Side only GYM application that helps you to manage your training, 
diet and track evolution, all in a single place.

## Data Requirements
- user: data for physical analysis.
    - username
    - sex
    - age
    - weight
    - height
- workoutGoup: A group of workouts for a specific training routine.
    - name
- workout: definition and metadata
    - name
    - bodyRegion
    - type [push/pull]
- execution: execution details
    - number of repetitions
    - date and time
    - duration
